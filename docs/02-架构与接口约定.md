# 架构与接口约定

## 调用关系

```text
Vue + Three.js
      |
      | /api/v1
      v
业务服务 server ------> MySQL / uploads
      |
      | 内部 HTTP
      v
算法服务 ai-service
```

- 浏览器只访问 `server`，不直接访问 `ai-service`。
- `server` 负责认证、业务规则、持久化和 AI 请求编排。
- `ai-service` 只负责照片关键点、参数估计和推荐算法，不保存业务数据。
- 开发环境由 Vite 将 `/api` 代理到 `http://localhost:8000`。

## HTTP 约定

- 对外路径统一以 `/api/v1` 开头。
- 成功响应：`{"code": 0, "message": "ok", "data": ...}`。
- 业务失败使用对应 HTTP 状态码，并返回稳定的业务错误码。
- 所有时间使用 ISO 8601 UTC；数据库统一保存 UTC。
- API 以 FastAPI 生成的 OpenAPI 为事实来源，Apifox 从 OpenAPI 导入。

## 模块责任

| 目录 | 责任 | 禁止事项 |
| --- | --- | --- |
| `frontend` | 页面、Three.js 场景、交互和状态 | 不复制 AI 或尺码业务算法 |
| `server` | 用户、商品、数字人配置、试穿记录 | 不直接实现计算机视觉算法 |
| `ai-service` | 关键点、参数映射、推荐算法 | 不访问用户和订单表 |
| `assets` | Blender 源文件与发布用 GLB 规范 | 不提交来源不明的素材 |
