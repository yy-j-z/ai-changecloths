# MVP 与验收标准

## 项目定位

本项目实现参数化 3D 数字人创建与虚拟试装。用户可以手动捏身材、捏脸、选择头发，或上传正脸照片生成初始脸型参数，然后在自己的数字形象上试穿服装。

系统提供的是视觉化形象与尺码建议，不宣称医学级人体测量、真人一比一重建或真实布料物理仿真。

## P0：答辩必须完成

| 模块    | 验收标准                                                               |
| ------- | ---------------------------------------------------------------------- |
| 账号    | 演示账号可以登录；数字人配置和试穿记录归属于用户                       |
| 数字人  | 支持胖瘦、身高、肩宽、胸围、腰围、臀围等至少 6 个参数                  |
| 捏脸    | 支持脸宽、下巴、眼睛、鼻子、嘴巴等至少 8 个参数                        |
| 外观    | 至少 4 款头发，支持肤色和发色选择                                      |
| 3D 展示 | 模型可旋转、缩放，并支持正面、侧面和背面查看                           |
| 试装    | 至少 8 件服装，可切换款式、颜色和尺码                                  |
| 动画    | 至少支持站立、转身、行走 3 个预制动作                                  |
| 推荐    | 根据用户输入和品牌尺码表推荐尺码，并说明合身程度                       |
| 记录    | 可以保存数字人、收藏服装、保存试穿截图和历史记录                       |
| 后台    | 可以维护商品、GLB 地址、颜色、尺码和库存                               |
| 智能体  | 能理解穿搭场景并调用商品、尺码、搭配和 3D 试穿工具；信息不足时主动追问 |

## P1：有余力完成

- 使用 MediaPipe Face Landmarker 将照片关键点映射为初始捏脸参数。
- 并排对比、穿搭海报和试穿热度统计。
- 使用摄像头姿态驱动数字人骨骼。

## 不作为验收承诺

- 单张照片精确恢复真人三维身体或厘米级围度。
- 任意服装自动生成可穿戴三维模型。
- 实时布料碰撞、褶皱和物理垂感。
- 直播级无延迟真人 AR 试穿。
